# Homebrew tap for macfreeapps

```sh
brew install --cask macfreeapps/tap/fanpilot
```

| Cask | What it is |
|---|---|
| [`fanpilot`](https://github.com/macfreeapps/fanpilot) | Menu-bar temperature and fan control for Apple Silicon Macs |

Casks here install apps that are **not notarized**; each cask clears the quarantine flag and says so in its caveats.
