# Homebrew tap for macfreeapps

```sh
brew install --cask macfreeapps/tap/fanpilot
brew install --cask macfreeapps/tap/kompx
brew install --cask macfreeapps/tap/cineframe
```

| Cask | What it is |
|---|---|
| [`fanpilot`](https://github.com/macfreeapps/fanpilot) | Menu-bar temperature and fan control for Apple Silicon Macs |
| [`kompx`](https://github.com/macfreeapps/kompx) | Local image and video compression for Apple Silicon and Intel Macs |
| [`cineframe`](https://github.com/macfreeapps/cineframe) | Cinematic photo crops with balanced 16:9 letterboxing |

Casks here install apps that are **not notarized**. See each cask's caveats for first-launch instructions. The FanPilot cask clears its quarantine flag; komPX and CineFrame use macOS's normal first-launch approval.
